# Ecosystem-Brain Memory Vault

Obsidian-style vault — the human window into the knowledge base Claude searches
semantically. Each note has YAML frontmatter and wiki-style links to related notes.

## Hubs
- [[roadmap]] — current state & decisions (read this first)
- [[projects-moc]] — every scaffolded project

## Structure
- `decisions/` — key architectural decisions (hook format, platform quirks)
- `projects/` — one card per project; each links to [[projects-moc]]
- `sessions/` — dated session logs (auto-generated by the SessionEnd hook)
- `maintenance/` — weekly heartbeat reports (auto-generated)
- `templates/` — note templates for the Templates plugin

## Key decisions
- [[hook-format]] — correct Claude Code hook structure
- [[windows-python-invocation]] — use `uv run python`, not bare `python`
- [[windows-path-translation]] — `/d/` works as a CLI arg, not inside Python code
- [[ollama-accented-path]] — OLLAMA_MODELS must be ASCII-safe
- [[powershell-utf8-bom]] — avoid Out-File `-Encoding utf8` (adds a BOM)
- [[claude-best-practices]] — conventions grounded in Anthropic's guidance
- [[agent-pinning]] — pin installed agents to commit SHAs
- [[model-routing]] — route agents by task shape (haiku / inherit)
- [[betting-tracker-stack]] — a project's stack decision

## Usage
```bash
# Rebuild the structural manifest (index.json)
uv run python /d/claude-projects/ecosystem-brain/skills/memory/memory-index.py

# Semantic search (requires Ollama running with nomic-embed-text)
uv run python /d/claude-projects/ecosystem-brain/skills/memory/memory-search.py search "QUERY"

# Offline fallback (hash embedder, no Ollama needed)
uv run python /d/claude-projects/ecosystem-brain/skills/memory/memory-search.py search "QUERY" --offline
```

## Active hooks (global, ~/.claude/settings.json)
- `PreToolUse` `if: Bash(git commit*)` → guard-secrets.sh (gitleaks scan)
- `PreToolUse` `if: Bash(git push*)` → guard-secrets.sh + guard-destructive.sh
- `PreToolUse` `if: Bash(rm *)` → guard-destructive.sh
- `PostToolUse` `if: Write(*.py)` → fmt-python.sh (ruff format + fix)
- `SessionStart` → suggest-agents.py (recommends relevant installed + catalog agents)
- `SessionEnd` → log-session.sh (dated session note in memory/sessions/)

Hook structure: `matcher` = tool name only; `if` = argument filter. See [[hook-format]].

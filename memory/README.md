# Ecosystem-Brain Memory Vault

Obsidian-style vault. Each note has YAML frontmatter + `[[wikilinks]]`.

## Structure
- `sessions/` — dated session logs (auto-generated by the SessionEnd hook)
- Individual decision/tool/convention notes linked from here

## Usage
```bash
# Rebuild the structural manifest
python ${CLAUDE_PLUGIN_ROOT}/skills/memory/memory-index.py

# Semantic search (requires Ollama + nomic-embed-text)
python ${CLAUDE_PLUGIN_ROOT}/skills/memory/memory-search.py search "QUERY"

# Offline fallback
python ${CLAUDE_PLUGIN_ROOT}/skills/memory/memory-search.py search "QUERY" --offline
```
